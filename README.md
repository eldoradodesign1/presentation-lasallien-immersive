# Hub Média Lasallien — présentation immersive

Ouvrir `presentation.html` dans un navigateur récent. La présentation fonctionne localement sans serveur : les images sont embarquées dans le dossier `assets/`.

## Navigation

Les flèches gauche/droite, la barre espace et les boutons en bas permettent de changer de scène. La touche `P` active ou désactive la lecture automatique. La touche `F` ou le bouton `⛶` active le plein écran. Sur mobile, faire glisser horizontalement pour naviguer.

## Contenu

La présentation comprend 19 scènes avec une narration immersive : couverture, point de départ, zoning, état existant, deux simulations après pour chacune des quatre pièces, chaîne technique, feuille de route, budget et décision proposée.

Les images marquées « Simulation conceptuelle » sont des projections visuelles destinées à illustrer une direction d’aménagement. Les dimensions, implantations et choix définitifs devront être confirmés par un relevé sur site et des devis locaux.
